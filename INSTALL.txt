NOCTIS v0.9.3 — STATS JSON REPAIR

This fixes the Stats error shown as:
"JSON Parse error: Unexpected identifier ..."

Why it happened:
The RP model sometimes ignored the instruction to return JSON and added normal prose.
The stats importer then tried to parse that prose as JSON.

What changed:
- Noctis now extracts a valid JSON object even if the model wraps it in prose or markdown.
- If the first result still cannot be parsed, Noctis automatically asks the SAME model once to repair its response into valid JSON.
- Failed scans do NOT alter your counters, scene stats, or RP.
- Existing v0.9.2 readability cleanup and bot-status badge remain included.

INSTALL
1. Make a Backup.
2. Replace:
   - index.html
   - stats.js
   - stats.css
3. Keep every other existing Noctis file.
4. Fully close/reopen Noctis after GitHub Pages updates.
5. Badge should read v0.9.3.
6. Tap Stats → Update From RP again.
