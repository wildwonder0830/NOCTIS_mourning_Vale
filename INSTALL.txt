WHAT'S NEW

STATS TAB
- Timeline-specific counters:
  Sex
  Kisses
  Dates
  Fights
  Transformations
  Major injuries
- +/- buttons let you correct counts manually.
- Current-scene participant cards:
  Name
  Species
  Health status
  Clothing worn
  Scene status / position
  Notes
- Chronological Story Beat Log.
- “Update From RP” reads only transcript messages not previously scanned,
  updates current-scene participants, and increments newly occurring beats.
- The scan is manual so it does NOT spend an extra model request on every RP turn.

FORMATTING
- Main RP dialogue: “curly quotation marks”
- Main RP actions/narration: **double-asterisk action formatting**
- Noctis displays **action text** in bold while preserving the stored markers.
- Phone messages remain plain text.

DATA SAFETY
- Stats live inside each timeline/chat, so separate RP worlds/timelines stay isolated.
- Stats are included automatically in normal Noctis vault backups.
