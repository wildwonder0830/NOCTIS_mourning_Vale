NOCTIS v0.12.0 — BESTIES + GROUP CHAT + LIVING SOCIAL FEED

This update makes the social/phone world much more alive.

BESTIES / GROUP CHAT
Phone → Contacts now has:
- Create Bestie Trio
- + Group Chat
- Groups button

Create Bestie Trio adds three editable friends:
- Mara — blunt ride-or-die
- Vivian — chaotic instigator
- Elena — calm observer

It also creates a group chat called “The Coven”.
All names, roles, photos, texting styles, and group membership can be edited later.

GROUP CHAT
- The protagonist can message the group.
- 1–3 friends may answer naturally; not everybody must respond every time.
- Each friend keeps her own voice.
- Group chat has access to recent main-story context.

SOCIAL
- Existing known phone contacts are automatically treated as followers the first time Social initializes.
- Social shows follower count.
- Refresh Feed generates status posts from contacts.
- NPC posts are about THEIR lives too, not only the protagonist.
- The protagonist can Like/Heart other people's posts.
- Contacts can still react/comment on her posts.
- Optional Ambient Social Activity can create occasional posts while Noctis is open.
  This is OFF by default because it uses model calls.

ALL PRIOR FIXES REMAIN INCLUDED
- RP pacing
- hard knot block
- house cannot text
- ambient incoming texts + unread notifications
- story contacts
- stats
- phone continuity
- formatting cleanup

INSTALL
1. Make a Noctis Backup.
2. Replace:
   - index.html
   - phone.js
   - phone.css
   - stats.js
   - stats.css
   - social.js
   - social.css
3. Keep app.js, styles.css, phone-fix.js, phone-fix.css, and all other files.
4. Fully close/reopen Noctis after GitHub Pages updates.
5. Build badge should read v0.12.0.
