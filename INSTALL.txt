NOCTIS v0.11.0 — SOCIAL + AMBIENT TEXTS

This includes the v0.10.1 fix that revoked the house's phone privileges.

NEW: SOCIAL TAB
- Twitter-style status feed inside each RP timeline.
- Protagonist can post short status updates.
- Phone contacts who have "Follows protagonist on Social" enabled can see the post.
- Contacts may instantly react or comment in their own established voice.
- Each contact card now has a Social follow toggle.
- Social posts/reactions travel with the timeline backup.

NEW: RANDOM / AMBIENT TEXTS
- Phone > Contacts now has "Ambient incoming texts".
- It is OFF by default because every spontaneous text uses an API/model call.
- Frequency choices:
  Rare: roughly every 1–3 hours
  Normal: roughly every 30–90 minutes
  Frequent: roughly every 15–45 minutes
- Messages only arrive while Noctis is open.
- Maximum 8 ambient texts per day per active timeline.
- Sleeping, Driving, and Do Not Disturb contacts are skipped.
- Contacts can react naturally to recent RP or Social posts.

NEW: NOTIFICATIONS
- Phone tab shows an unread count/dot.
- Individual contact pills show unread counts.
- Opening a contact marks that thread read.

INSTALL
1. Make a Noctis Backup.
2. Replace:
   - index.html
   - phone.js
   - phone.css
   - stats.js
   - stats.css
3. ADD:
   - social.js
   - social.css
4. Keep phone-fix.js, phone-fix.css, app.js, styles.css and all other existing files.
5. Fully close/reopen Noctis after GitHub Pages updates.
6. Build badge should read v0.11.0.
