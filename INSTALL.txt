NOCTIS v0.10.0 — STORY CONTACTS

Phone now has a real story-world contact directory.

NEW
- Contacts button directly inside Phone.
- + Contact for anyone in the story: ex, brother, friend, coworker, rival, etc.
- Every contact gets a separate text thread.
- Contact cards now include Relationship / Role.
- Sync From Story can pull people already known from Stats scene participants,
  the main cast, and clearly person-based lore entries.
- Tap a contact to open their thread.
- Edit jumps to the full contact editor for picture, display name, status,
  relationship, and custom texting style.

Sync From Story is intentionally conservative so Noctis does not create contacts
for random places, objects, or one-off nouns. Anyone missed can be added with + Contact.

INSTALL
1. Make a Noctis Backup.
2. Replace:
   - index.html
   - phone.js
   - phone.css
   - stats.js
   - stats.css
3. Keep phone-fix.js and phone-fix.css and all other files.
4. Fully close/reopen Noctis after GitHub Pages updates.
5. Build badge should read v0.10.0.

All prior fixes through v0.9.7 remain included.
