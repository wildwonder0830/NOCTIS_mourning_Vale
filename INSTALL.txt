NOCTIS v0.9.4 — NO MORE JSON STATS

The selected RP model keeps refusing strict JSON, so this version stops asking it for JSON entirely.

STATS NOW USE A SIMPLE LINE PACKET:
sex=0
kisses=0
dates=0
fights=0
transformations=0
majorInjuries=0

PARTICIPANT|name|species|health|clothing|status|notes
BEAT|type|detail

This is much easier for RP models to follow and much easier for Noctis to parse.

INSTALL
1. Make a Noctis Backup.
2. Replace:
   - index.html
   - stats.js
   - stats.css
3. Keep every other existing Noctis file.
4. Fully close/reopen Noctis after GitHub Pages updates.
5. Build badge should read v0.9.4.
6. Tap Stats → Update From RP again.

Nothing from failed v0.9.3 scans was counted, so you will not get duplicate stats from those failures.
The readability cleanup and Send-button bot-status badge are still included.
