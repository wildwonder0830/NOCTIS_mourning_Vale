NOCTIS v0.12.3 — VERSION BADGE FIX

You found a real UI bug.

Several older extension files still have their own historical version constants:
- phone.js reports v0.12.0 internally
- stats.js reports v0.12.0 internally
- social.js reports v0.12.0 internally
- import-fix.js reports v0.12.1
- phone-rp-sync.js reports v0.12.2

They all write to the SAME badge.

That is why Library could show v0.12.2, then Chat could flip back to v0.12.0 after
Stats/Social re-rendered. The feature patch was still loaded; the badge was just being overwritten.

FIX
v0.12.3 adds one final version authority so the top badge always reflects the installed app bundle.

INSTALL
1. Replace index.html.
2. Add build-version.js.
3. Keep every other file exactly as-is.
4. Fully close/reopen Noctis.
5. Badge should stay v0.12.3 on Library, Chat, Phone, Stats, Social, etc.
