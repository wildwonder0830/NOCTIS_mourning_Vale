NOCTIS v0.13.0 — STRUCTURED PHYSICAL CANON

This version separates stable physical facts from the large Appearance/Body prose box.

NEW STRUCTURED FIELDS — CHARACTER
- Species / Nature
- Height
- Weight
- Build / Body Type
- Eye Color
- Hair Color
- Hair Length / Style
- Skin Tone
- Distinguishing Features
- Apparent Age
- Actual Age
- Current Form

NEW STRUCTURED FIELDS — PERSONA
- Height
- Weight
- Build / Body Type
- Eye Color
- Hair Color
- Hair Length / Style
- Skin Tone
- Distinguishing Features
- Apparent Age
- Actual Age
- Current Form

Existing Species / Nature remains in the Persona sheet.

WHY
Structured facts are now appended to the model prompt as PHYSICAL CANON.
If prose and a structured fact conflict, the structured fact wins.
That should greatly reduce drift such as 4'11" Amanda suddenly being the same height as Henry.

JSON
Persona exports now include all structured physical fields and targetSlot.
Persona imports accept those fields.
Character-card JSON imports recognize common keys such as:
height, weight, build/body_type, eyeColor/eye_color/eyes, hairColor,
hairStyle, skinTone/complexion, distinguishingFeatures, apparentAge,
actualAge, currentForm, and species/race/nature.
