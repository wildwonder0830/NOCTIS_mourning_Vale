NOCTIS v0.13.3 — MULTI-DEVICE MERGE

This fixes the exact situation where two devices have diverged.

YOUR CURRENT CASE
- iPad Jesse: 143 chat messages
- iPhone Jesse: 119 chat messages
- Henry was started on the iPhone, so Henry has newer iPhone-only history

The old Sync importer REPLACES the current vault. That is unsafe when BOTH devices have unique newer data.

NEW BUTTON
Sync → Merge Vault File

Merge keeps unique information from both sides instead of replacing one with the other.

REPAIR STEPS

1. BACK UP BOTH DEVICES FIRST.
   iPad: Sync → Share Current Vault → save the iPad file.
   iPhone: Sync → Share Current Vault → save the iPhone file.

2. Use the iPad as the temporary master because it has the longer Jesse history.

3. Install this v0.13.3 patch on the iPad.

4. On the iPad:
   Sync → Merge Vault File → choose the iPHONE vault file.

5. Verify:
   - Jesse should keep all unique messages. If the phone's 119 are the same first 119 of the iPad's 143, Jesse remains 143.
   - Henry and his iPhone-only history should now appear on the iPad.
   - Phone threads, contacts, lore, personas, social posts, milestones, etc. are also merged.

6. On the iPad, Sync → Share Current Vault again.
   That NEW export is now the merged master.

7. On the iPhone, use Import Vault Here with the NEW merged master file.
   Now both devices start from the same vault again.

AFTER THIS
If only one device has new work, ordinary Import Vault Here is fine.
If BOTH devices have new work, use Merge Vault File before replacing either copy.

INSTALL
- Replace index.html
- Replace build-version.js
- Add merge-sync.js
- Keep every other file exactly as-is
- Fully close/reopen Noctis
- Badge should read v0.13.3
