NOCTIS v0.11.1 — HARD KNOT BLOCK

The prompt alone was not strong enough. This version adds THREE layers:

1. High-priority final system rule
   - It is appended AFTER recent transcript/context so old wording cannot override it.
   - Sexual uses of knot/knotting/tie/bulbus glandis are explicitly non-canon.

2. Runtime output sanitizer
   - If the model STILL produces "knot" as sexual anatomy, Noctis rewrites it
     before the reply is saved/displayed.
   - Ordinary nonsexual uses of "knot" (rope knot, stomach in knots, tying a knot)
     are left alone as much as possible.

3. Existing-message cleanup
   - Clearly sexual "knot" wording in assistant posts is cleaned when messages render.
   - This helps stop the model from seeing/reinforcing its own bad terminology later.

Doggy style and primal/animalistic energy remain allowed. This ONLY targets canine
reproductive anatomy/mechanics.
